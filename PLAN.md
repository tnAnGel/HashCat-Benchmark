## Правило завершения батча

Для каждой цели: сверить папку → найти первичный/публичный источник → проверить, что вывод относится именно к этой GPU → оформить отчёт в её папке → обновить `GPU.md` и реестры → пересчитать итоги. Не коммитить и не пушить в рамках этого плана без отдельного запроса.

## Результат первого параллельного поискового прохода

Проведён параллельный поисковый проход по отдельным группам GPU, результаты сверены с первоисточниками. Добавлены три GPU-папки: Tesla P40 (доступный фрагмент raw-лога 2019 года, версия hashcat в публикации не указана), NVIDIA A40 (полный raw `v6.2.5`, риг 8×, таблица использует показатели `Speed.#1`) и AMD Instinct MI300X (частичный raw сторонней сборки `v6.2.6-854-g3033ed126`). MI250X/MI250 имеет raw для одного режима на 8 устройствах, но сам вывод не различает варианты — оставлен как неоднозначное свидетельство, без отдельной папки.

На этом проходе подтверждённого успешного raw-лога не найдено для RDNA3 midrange/RDNA4, workstation W6800/W7800/W7900, Instinct MI100/MI210/MI300A, NVIDIA A4500/Quadro RTX 8000/RTX Ada desktop, Intel Arc A750/A580/A380/A310, Tesla K40/V100 32GB/A16/A30/B100/GB200 и большинства новых mobile GPU. Для некоторых из них существуют только агрегированные Phoronix/OpenBenchmarking таблицы; их не заносил как raw benchmark. У RTX 7800 XT опубликован прогон, завершающийся ошибкой компиляции без `Speed`; у RTX 5050 также найден неуспешный запуск без скоростей.

Полезные первичные источники: [Tesla P40](https://www.reddit.com/r/hacking/comments/cz6jat/hashcat_benchmark_on_geforce_now/), [NVIDIA A40](https://github.com/x-agent314/gpu_cloud_benchmarks/blob/main/hashcat_benchmark_8xA40.txt), [MI300X](https://gitlab.com/-/snippets/4805487), [MI250/MI250X](https://hashcat.net/forum/printthread.php?tid=11889), [RX 7800 XT — неуспешный прогон](https://hashcat.net/forum/printthread.php?tid=12195).

## Дополнение: проверка источников и новые raw-карточки

В ещё одном проходе сверены Hashcat Forum, GitHub raw-архив, gist, Reddit и Pastebin. Добавлены 16 GPU source-карточек: AWS P3 8×V100 (`v6.0.0`), RTX 5090 (`v6.2.6`), Tegra X1 в Nintendo Switch (`v6.2.6`), Arc A770 (`v6.2.6`), Iris Xe Raptor Lake-P (partial MD5, `v6.2.6-827`), Radeon Pro 5500M (mode 11600, `v6.2.5-383`), RX 580 2048SP (`v6.2.6`), плюс девять новых raw для RTX 3060, 3070, 3070 Ti, 3080 Ti, 3090 (два прогона/конфигурации), 4070 Ti SUPER, 4080 SUPER и 4090 (14× риг). У RTX 3090 отдельно помечен 5× v7.0.0 прогон; многокарточные суммарные скорости не смешиваются с per-device результатами. Всего теперь 535 GPU Markdown-карточек.

Ложный lead исключён: Hashcat Forum thread 11254 содержит скорость обычной сессии перебора пароля на V100, а не режим benchmark `-b`; это не внесено как benchmark. Повторный поиск CPU по Tier A не дал новых полных, однозначных raw-логов; новые частичные сведения по Core i7-1165G7, Ryzen 9 9900X, Core i7-14700K, Threadripper 3990X и Xeon E3-1270 v5 уже оформлены в CPU-карточках соответствующего типа.

Остаются незакрытыми этапы 0.2–0.3 (ручная сверка алиасов и полный проход по mobile-реестрам), сбор по 540 открытым GPU-целям и более широкий поиск CPU вне уже заведённых карточек. Поэтому этот файл — живой план работ, а не заявление о полном исчерпании всех когда-либо опубликованных тестов.

В последнем CPU-проходе добавлены 10 карточек на 10 моделей: три benchmark-режима `-b`/raw или partial (Apple M1 per-device из смешанного запуска, Intel Core i7-4770K PoCL/Intel mode 1000, Ryzen 7 1700X v3.40 CPU-only), три опубликованных CPU/OpenCL-строки iVision mode 23410, один MD4 CPU-only результат из публикации и три WPA2 dictionary-attack результата. Последние семь не являются стандартным `hashcat -b` benchmark и в ranking не включены. Источники и ограничения записаны в карточках; полный указатель CPU синхронизирован с 285 модельными папками.

В дополнительном проходе добавлены raw partial-карточка Arc A770M (9 режимов), отдельные summary-only mode 22000 строки Arc A310/A380 из проприетарного Hashcat-ng (не upstream Hashcat) и опубликованные пять скоростей MI300X из исследования Specops. Карточки без опубликованных скоростей не сохраняются в каталоге результатов.
