# 🔓 HashCat Benchmark — коллекция тестов оборудования

Коллекция публичных результатов Hashcat для видеокарт и процессоров всех
поколений. В каждой папке устройства лежат отдельные `.md`-карточки. Raw-вывод,
частичные логи, PTS-результаты и опубликованные comparison-таблицы явно
разделяются по типу свидетельства; обработанные цифры не выдаются за RAW.

> Каждое устройство — **отдельная папка**. Внутри — один или несколько документов
> (`.md`) с указанием устройства, скоростей и источника: raw-выводом, частичным
> фрагментом или PTS-таблицей. Тип свидетельства явно отмечается в карточке.

---

## 🗂️ Два раздела

| Раздел | Что внутри | Индекс |
|---|---|---|
| 🎮 **[`GPU/`](GPU)** | 293 папки видеокарт/графических устройств с benchmark-карточками | **[GPU.md](GPU.md)** — сводная таблица и полный указатель |
| 🧠 **[`CPU/`](CPU)** | 285 процессоров с raw, partial или явно помеченным сравнительным результатом | **[CPU.md](CPU.md)** — сводная таблица и указатель |

Результаты OpenBenchmarking разложены по папкам соответствующих устройств в
отдельные `.md`-карточки: индивидуальные PTS-прогоны и агрегаты профиля
разделены и явно помечены. PTS не публикует для этих записей исходный stdout
Hashcat, поэтому такие карточки не называются RAW и не смешиваются с сырыми
логами. Другие сводные источники и ограничения описаны в
[`PUBLIC-AGGREGATES.md`](PUBLIC-AGGREGATES.md).

Структура:

```
HashCat-Benchmark/
├── GPU/
│   ├── NVIDIA GeForce RTX 4090/
│   │   └── NVIDIA GeForce RTX 4090 — Chick3nman v6.2.6.md
│   └── ...                          (293 папки)
├── CPU/
│   ├── Intel/
│   │   ├── Core i9/ · Core i7/ · Xeon/ ...
│   └── AMD/
│       ├── Ryzen 9/ · EPYC/ ...
├── GPU.md            # сводная таблица видеокарт
├── CPU.md            # сводная таблица процессоров
├── COVERAGE.md       # трекер покрытия GPU (десктоп/DC)
├── MOBILE.md · MOBILE-ROSTER.md   # мобильные GPU
├── PUBLIC-AGGREGATES.md # заметки о публичных источниках и нерешённых aliases
└── CPU-ROSTER.md · CPU-RANKING.txt # реестр целей CPU (4240 моделей)
```

Разделять важно: при масштабе в тысячи процессоров общая куча папок в корне
делает репозиторий непросматриваемым (веб-интерфейс GitHub обрезает листинг на
~1000 записях), а сравнивать CPU и GPU в одной таблице бессмысленно — это разные
классы железа.

## 📖 Как читать результаты

Строка вида:

```
Speed.#1.........: 164.1 GH/s (69.78ms) @ Accel:512 Loops:1024 Thr:64 Vec:1
```

- `Speed.#1` — скорость устройства №1 (одно устройство); `Speed.#*` — суммарно по всем;
- `GH/s` — миллиардов хешей в секунду;
- `Accel/Loops/Thr/Vec` — параметры автотюнинга ядра.

## 🔬 Как снять свой бенчмарк

```bash
hashcat -b                       # стандартный набор режимов
hashcat -b -O                    # оптимизированные ядра (быстрее, ограничение длины)
hashcat -b --benchmark-all       # ВСЕ поддерживаемые режимы
hashcat -b -m 3200               # конкретный режим (bcrypt)
```
