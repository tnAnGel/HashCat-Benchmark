# NVIDIA Tesla V100-SXM2-16GB — Hashcat v6.0.0 (AWS P3.16xlarge, 8× GPU)

- **Тип свидетельства:** опубликованный raw stdout `hashcat -b`; 8 идентифицированных CUDA-устройств, значения `Speed.#1` ниже относятся к одной карте. Полный вывод и все восемь скоростей опубликованы в источнике.
- **Hashcat:** v6.0.0, CUDA 11.0, optimized kernel (`-O`).
- **Источник:** [Hashcat Forum — AWS P3.16xlarge benchmarks](https://hashcat.net/forum/thread-9384.html).
- **Важно:** восемь GPU одновременно дают суммарный `Speed.#*`; здесь приведены значения устройства #1, а не общая скорость инстанса.

| Mode | Алгоритм | `Speed.#1` |
|---:|---|---:|
| 0 | MD5 | 56.1376 GH/s |
| 100 | SHA1 | 17.7489 GH/s |
| 1400 | SHA2-256 | 7.7064 GH/s |
| 1700 | SHA2-512 | 2.4032 GH/s |
| 22000 | WPA-PBKDF2-PMKID+EAPOL | 867.8 kH/s |
| 1000 | NTLM | 102.2 GH/s |

Страница содержит исходный `hashcat -b` вывод, имена восьми устройств и per-device `Speed.#1`–`Speed.#8`; файл здесь фиксирует выбранные показатели без выдачи агрегированной скорости рига за скорость одной карты.
