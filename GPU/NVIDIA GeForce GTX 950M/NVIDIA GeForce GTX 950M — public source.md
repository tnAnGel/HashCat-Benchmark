# NVIDIA GeForce GTX 950M

- **Видеокарта / GPU:** NVIDIA GeForce GTX 950M
- **Статус коллекции:** ⬜ стандартный benchmark `hashcat -b` не подтверждён
- **Источник устройства:** [hashcat forum — GTX 950M видна как устройство OpenCL](https://hashcat.net/forum/showthread.php?mode=threaded&pid=38853&tid=7222)
- **Внешний ориентир:** [таблица Hashcat-ng](https://gist.github.com/GermanAizek/f968d0bb213b2b7c8d9b35bbc4d031e4) приводит значение `59020`.
- **Ограничение:** таблица относится к Hashcat-ng, проприетарному форку для WPA-PBKDF2-PMKID+EAPOL; единица и методика этого значения в источнике не описаны. Оно не записывается как скорость официального hashcat.

Форумный вывод подтверждает обнаружение GTX 950M драйвером, но не содержит результата benchmark-режима.
